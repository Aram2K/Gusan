## Faster, lighter, smaller

Gusan 2.1.10 is quicker to use, takes less memory and less disk space, and its download is smaller. Nothing you use changes. Your settings, history, meetings and sign-in are kept.

### 🎯 Better

- **Pages open faster.** Pages build in a fraction of the time, and the Meetings list opens at once when nothing in it changed.
- **Cloud requests start sooner.** Smart Actions, dictation on Gusan Cloud, caption translation and the Live Assistant no longer spend about half a second getting each new connection ready.
- **Quicker dictation on this computer with automatic language.** The start of each take is no longer read twice to find its language.
- **Less memory.** Gusan holds much less memory while it waits.
- **Recordings take about half the space.** A few hours after a meeting, its separate microphone and call recordings are stored compressed, with no sound lost. The meeting plays, exports and labels speakers as before.
- **A smaller download.** Parts Gusan never used are left out.
- **Updates clean up after themselves.** An update removes the previous version's files before installing, and an installer left behind by an older update is deleted. A downloaded speech model is no longer stored twice, and Gusan's own log file no longer grows without end.

### 🛠️ Fixes

- **No pause when you change a setting.** Saving a setting froze Gusan for a second or two while it redrew its icon.

Download file names still start with TranscribeApp, so updates keep working.
