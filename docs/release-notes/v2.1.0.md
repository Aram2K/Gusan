## New Gusan Pro plans

Gusan 2.1.0 changes how Gusan Pro is sold. Your settings, history, meetings and sign-in are kept.

### Plans

- **Monthly.** €15.99 a month. Cancel anytime.
- **Yearly.** €9.99 a month, billed every month, for 12 months (€119.88 over that year). You can cancel at the end of those 12 months, not before. After that, billing continues at €9.99 a month until you cancel.
- **Lifetime.** €199 once, for the first 200 people.
- **No trial.** Gusan Pro starts when you pay.

### Free

- **One cloud meeting note and one Live Assistant session each month.**
- **Smart Actions on this computer are included, with no monthly cap.** Dictation and audio to text on this computer stay included too. Gusan Cloud speech is part of Gusan Pro.

Download file names still start with TranscribeApp, so updates keep working.
