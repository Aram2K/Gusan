# Gusan on phones

| Folder | App | Language | Build |
|---|---|---|---|
| [`ios/`](ios/README.md) | Gusan for iPhone: the keyboard, voice, Agent, Vault, Gusan Screen | Swift | [iOS workflow](../.github/workflows/ios.yml), unsigned IPA |
| [`android/`](android/README.md) | Gusan for Android: the keyboard with voice, and a meeting recorder with notes | Kotlin | [Android workflow](../.github/workflows/android.yml), debug APK |

Both use the same account and the Gusan Cloud functions in `supabase/functions/`. The planning
documents for the iPhone app are in [`docs/ios/`](../docs/ios/README.md).
